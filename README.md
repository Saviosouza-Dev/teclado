# Primeiros Acordes no Teclado — Cartilha do Aluno

Material de apoio para aulas de teclado iniciante, em página única.
Feito para o aluno abrir no celular ou no computador, sem instalar nada.

**Acesse aqui:** https://saviosouza-dev.github.io/teclado/

## O que tem dentro

- As partes do teclado
- Postura e altura certa
- Suas mãos e os números dos dedos
- Teclas brancas e pretas: o padrão que se repete
- Achar o Dó e o nome das notas
- Como ler uma cifra e um diagrama
- Seus primeiros 4 acordes (C, G, Am, F)
- Exercícios de troca de acordes
- Seu primeiro acompanhamento
- Dúvidas frequentes

## Como funciona

Todo o conteúdo está em `index.html` — um arquivo só, sem dependências além
das fontes do Google Fonts. Layout responsivo (celular, tablet e desktop) e
folha de estilo para impressão, caso o aluno prefira o material em papel.

Os diagramas de acorde são desenhados por código a partir da lista `chordDefs`
no fim do arquivo: para acrescentar um acorde novo, basta um item novo ali.

## Para editar

Abra `index.html` em qualquer editor, salve e publique:

```bash
git add .
git commit -m "Descreva a alteração"
git push
```

O GitHub Pages atualiza o site em cerca de um minuto.
